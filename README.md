# Distributed Performance Engineering Platform

An open-source performance engineering platform built using
Grafana k6, Docker, Kubernetes, and CI/CD.

## Objectives

- Reusable and configuration-driven performance tests
- Smoke, load, stress, and soak testing
- Distributed execution using k6 Operator
- Automated performance quality gates
- Monitoring and reporting
- CI/CD integration

## Status

Phase 1: Local framework development.

## Technology Stack

- Grafana k6
- JavaScript
- Docker
- Kubernetes
- GitHub Actions
- Prometheus and Grafana
